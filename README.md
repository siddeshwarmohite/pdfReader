# PDF Viewer with Analysis Panel

A professional PDF viewer application with interactive text highlighting and analysis capabilities.

## Features

- Interactive PDF viewing with zoom controls
- Scroll-based page navigation
- Text highlighting with smart text detection
- Analysis panel with clickable reference links
- Responsive layout with 75/30 split view

## Installation

Install the required packages:

```bash
npm install
```

## Running the Application

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- react-pdf
- PDF.js
